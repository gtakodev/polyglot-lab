# Préparer son environnement

[Retour à l’accueil](README.md)

Vérifie uniquement le langage choisi. Aucun ancien inventaire ne prouve ce qui est installé aujourd’hui.

| Langage | Vérifier les versions |
|---|---|
| Java | `java --version` et `javac --version` |
| Kotlin | `java --version` et `kotlinc -version` si tu utilises le compilateur directement |
| Go | `go version` |
| Rust | `rustc --version` et `cargo --version` |
| TypeScript | `node --version` et `npm --version`, puis le compilateur installé dans ton projet |

Une commande absente signale un outil à installer ou un PATH à corriger. Pars du portail officiel de ton parcours pour l’installation et le choix du build. Vérifie la compatibilité des versions choisies.

Avant le projet, compile un programme minimal et exécute un test. Note les versions et les commandes réussies dans ton journal. Si tu bloques, donne à l’agent la commande exacte et son message d’erreur.

Les parcours n’imposent pas de shell POSIX.
