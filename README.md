# Polyglot Lab

Apprendre à programmer dans cinq langages en cherchant, en expérimentant et en expliquant ses choix. Tu écris le code ; l’agent te guide une question à la fois.

## Commence ici

1. Choisis **un seul parcours** ci-dessous. Si tu hésites, commence par Java.
2. Ouvre sa section **Première session** et suis-la. Tu n’as pas à lire le reste du dépôt.
3. Aux sessions suivantes, reprends la prochaine action notée dans ton journal.

| Parcours | Ce que tu construis |
|---|---|
| [Java](docs/parcours/java.md) | Catalogue de livres |
| [Kotlin](docs/parcours/kotlin.md) | Agrégateur de bulletins |
| [Go](docs/parcours/go.md) | Vérificateur HTTP |
| [Rust](docs/parcours/rust.md) | Recherche dans les fichiers |
| [TypeScript](docs/parcours/typescript.md) | Explorateur JSON |

Chaque parcours avance de P0 à P4. P0 produit une première version utilisable ; chaque palier ajoute un besoin précis. Termine un palier avant de préparer le suivant. Les extensions sont facultatives.

## Les seuls documents utiles au quotidien

- **Ton parcours** donne le travail et les critères de réussite.
- **Ton journal** garde ta recherche, tes observations et la prochaine action.
- [La progression](PROGRESS.md) indique les paliers vérifiés.

La [méthode](docs/methode.md) précise l’aide et la validation si tu en as besoin. [L’environnement](TOOLCHAINS.md) sert en cas de difficulté d’installation. Ce ne sont pas des lectures préalables.

Le code va dans `projects/<langage>/`, les petits essais dans `experiments/<langage>/`. Tu crées ces dossiers quand tu en as besoin et tu écris tes tests.
